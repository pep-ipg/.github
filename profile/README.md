# Pardakht Electronic Pasargad APIs

ابزارها، کتابخانه‌ها و راهنماهای فنی برای پیاده‌سازی سرویس‌های **پرداخت الکترونیک پاسارگاد (PEP)**: درگاه پرداخت اینترنتی، سرویس‌های پرداخت مبتنی بر حساب و سرویس‌های شاپرکی.

هدف این مجموعه کوتاه کردن زمان پیاده‌سازی برای پذیرندگان و توسعه‌دهندگان است: راهنمای دقیق، نمونه کد آماده و ابزار تست.
